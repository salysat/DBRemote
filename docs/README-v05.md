# DB Remote v0.5 — Light Multi-page Console

## الإدارة
- لوحة الإدارة: http://localhost:5080/dashboard.html
- أجهزة الفروع: /devices.html
- التحكم: /remote.html
- نقل الملفات: /transfers.html
- الإعدادات: /settings.html
- الأحداث: /activity.html

### مفتاح الإدارة
مفتاح الإدارة `DBREMOTE_ADMIN_TOKEN` موجود على **السيرفر فقط** ويُدخل في لوحة الإدارة، ولا يُرسل إلى الفروع. للحصول عليه في PowerShell على السيرفر:
```powershell
. .\.dbremote-secrets.ps1
$env:DBREMOTE_ADMIN_TOKEN
```
تعامل معه ككلمة مرور إدارية. إذا ظهر علنًا في لقطة شاشة، قم بتدويره. **لا ترسل المفتاح عبر الرسائل**.

### عميل الفرع
عميل الفرع يرسل طلب تسجيل ويحتفظ باعتماده الخاص بعد الموافقة. لا تضع مفتاح الإدارة في Agent. في `localhost` فقط يمكنك استخدام `ws://localhost:5080`؛ من أي فرع آخر استخدم `wss://` مع شهادة TLS صحيحة.

### خطأ 404 على /api/devices
هذا يعني عادةً تشغيل نسخة سيرفر لا تتضمن API تسجيل الأجهزة. أغلق السيرفر القديم وشغّل `start-server.ps1` من هذا المجلد، ثم افتح `/health` و`/api/devices` (الأخير يتطلب توثيقًا ويرجع 401 بدون مفتاح، لا 404).

### تنبيه
هذا تصميم محلي/تجريبي. مفتاح الإدارة يُحفظ ضمن `sessionStorage` للتنقل بين صفحات التبويب نفسه، ويُحذف عند إغلاق تبويب المتصفح عادةً؛ ويمكن الوصول إليه من JavaScript، لذلك لا تنشر النظام خارجيًا قبل استبداله بجلسة خادم تعتمد Cookie آمنة وMFA وCSRF protection. لا يُنصح باستخدامه على أجهزة مشتركة. برنامج Windows الجديد يحتاج `dotnet publish` على Windows للتحقق من التجميع.
